# e-Laporan Koku SKRT

Halaman pembalut GitHub Pages untuk web app **e-Laporan Mingguan Kokurikulum SK Rimba Terjun**.

Halaman ini membenamkan web app Google Apps Script dalam satu skrin penuh supaya banner
"This application was created by a Google Apps Script user" tidak dipaparkan.

- Laman: https://mohdruzani01-lgtm.github.io/elaporan-koku/
- Untuk tukar web app, ubah nilai `WEB_APP_URL` dalam `index.html`.
- Web app mesti menggunakan `setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)` dalam `doGet`.
